# ADR-0003: Identity and trust are deferred, not implied

Status: Open design gate.

No anonymity, sealed-sender, authenticated delivery, trust continuity, rotation, or revocation claim is allowed. Before Mesh returns, a separate reviewed ADR must define root signing keys, Noise static keys, contact introduction, fingerprints, TOFU/reset behavior, rotation continuity, revocation, backups/clones, recipient binding, and metadata disclosures.
